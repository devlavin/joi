# Joi 🤖 - Esta é a versão 0.1

> Um chatbot baseado em regras para reconhecimento de intenções, desenvolvido em TypeScript.

Joi é uma biblioteca simples de processamento de conversas que identifica intenções do usuário através de padrões definidos, sem depender de inteligência artificial ou modelos externos.

O objetivo é oferecer uma base leve, rápida e personalizável para criação de chatbots determinísticos.

---

## Funcionalidades

- Reconhecimento de intenções baseado em regras
- Sistema simples de mensagens e respostas
- Tipagem forte usando TypeScript
- Fácil criação de novos comandos/intenções
- Sem dependência de APIs de IA
- Testando no terminal
