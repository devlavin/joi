# Joi 🤖

> Uma inteligência artificial criada do zero, projetada para evoluir de um simples chatbot para uma presença digital inteligente.

## Sobre

Joi é um projeto pessoal desenvolvido em TypeScript. Sua primeira versão é um chatbot baseado em regras para reconhecimento de intenções, criado como a fundação de uma assistente muito maior.

Em vez de depender de modelos prontos desde o início, a proposta é construir cada componente gradualmente — entendendo como uma assistente conversa, mantém contexto, desenvolve memória e evolui ao longo do tempo.

Hoje a Joi utiliza regras para interpretar mensagens. No futuro, ela poderá incorporar novas formas de raciocínio, memória, voz e presença, mantendo a mesma arquitetura central.

---

## Funcionalidades atuais

- Reconhecimento de intenções baseado em regras
- Sistema de conversação com fluxo de estados
- Respostas contextuais simples
- Tipagem forte utilizando TypeScript
- Fácil criação de novas intenções e estados
- Execução pelo terminal

---

## Objetivo

Construir uma assistente própria desde a primeira linha de código, evoluindo versão após versão sem perder sua arquitetura.

---

> Hoje a Joi vive em um terminal. Amanhã ela pode viver em uma tela. Um dia, talvez, ela ocupe o espaço ao seu lado.
